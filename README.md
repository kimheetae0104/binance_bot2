# 🤖 바이낸스 ML 급등 예측 자동매매 봇

머신러닝 기반 암호화폐 급등 예측 및 자동매매 시스템

## 📋 주요 특징

### 💰 지능형 매매 전략
- **100만원 이하**: 올인 매매 (95% 자금 투입)
- **100만원 초과**: 분할 매매 (최대 5개 종목, 종목당 20%)
- 모든 USDT 페어 실시간 스캔 및 분석
- 최고 급등 가능성 종목 1개 자동 선택

### 🎯 리스크 관리
- **고정 손절**: -3% 도달시 무조건 청산
- **트레일링 스탑**: 상승 시 자동으로 익절선 상향 조정
- 매매 모드별 차별화된 트레일링 (올인: 1.5%, 분할: 2%)

### 🧠 머신러닝 예측
- XGBoost, LightGBM, Random Forest 앙상블
- 100+ 기술적 지표 자동 생성
- 실시간 예측 정확도 모니터링
- 자동 모델 재훈련 (12시간마다)

### 📊 실시간 대시보드
- 전략별 성과 추적 (올인 vs 분할)
- 거래 기록 및 손익 분석
- ML 모델 정확도 통계
- 일일/주간/월간 리포트

### 📱 텔레그램 알림
- 진입/청산 실시간 알림
- 포트폴리오 요약 (30분마다)
- 대시보드 리포트 (2시간마다)
- 오류 알림

## 🚀 빠른 시작

### 1. 환경 설정

```bash
# 1. 저장소 클론
git clone <repository>
cd binance_bot2

# 2. 패키지 설치
pip install -r requirements.txt

# 3. 환경 변수 설정
cp .env.example .env
# .env 파일을 편집하여 API 키 입력
```

### 2. .env 파일 설정

```bash
# Binance API (필수)
BINANCE_API_KEY=your_api_key
BINANCE_SECRET_KEY=your_secret_key
USE_TESTNET=True  # 테스트넷: True, 실제거래: False

# 거래 설정
TRADE_MODE=paper  # paper(가상) 또는 live(실제)
MIN_USDT_24H_VOLUME=300000  # 최소 24h 거래량
ML_PROB_THRESHOLD=0.55  # ML 예측 임계값

# 텔레그램 알림 (선택)
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
```

### 3. 테스트 실행

```bash
# 전체 시스템 테스트
python test_smart_bot.py
```

### 4. 봇 실행

```bash
# 메인 봇 실행
python main.py
```

- **트레일링**: 2% (보수적)
- **목표**: 리스크 분산 및 안정적 수익

1. 모든 USDT 페어 스캔 (65개+ 종목)
2. ML 앙상블 예측 (확률 계산)
3. 신뢰도 가중치 적용
4. 최고 점수 1개 종목 선택
5. 기존 보유 여부 확인
6. 매매 실행

## ⚠️ 주의사항

### 리스크 관리
- **테스트넷 먼저**: 반드시 테스트넷에서 충분히 테스트
- **소액 시작**: 실제 거래시 소액부터 시작
- **손실 한도**: 감당 가능한 금액만 투자
- **시장 변동성**: 암호화폐는 고변동성 자산

### 기술적 제한
- **API 제한**: 바이낸스 API 호출 제한 준수
- **네트워크**: 안정적인 인터넷 연결 필요
- **서버 운영**: 24시간 실행을 위한 VPS 권장

## 🛠️ 문제 해결

### 일반적인 문제
1. **API 키 오류**: .env 파일의 API 키 확인
2. **잔고 부족**: 최소 거래 금액 확인 ($10 이상)
3. **네트워크 오류**: 인터넷 연결 상태 확인
4. **모델 로드 실패**: 초기 실행시 모델 자동 훈련

### 로그 확인
```bash
# 최근 로그 확인
tail -f logs/trading_bot.log

# 오류 로그만 확인
grep ERROR logs/trading_bot.log
```
