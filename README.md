# 바이낸스 퀀트 트레이딩 — 암호화폐 시그널 ML 파이프라인

수백 개 USDT 페어의 **급등 시그널을 정량적으로 포착**하는 ML 트레이딩 파이프라인. 사람이 차트를 매번 훑는 비효율 대신 모델로 후보를 좁히고, 임계값 위 신호만 알림.

> 단기 수익보다 **살아남는 시스템**에 집중. 페이퍼 트레이딩 우선, 데이터 누적 우선.

---

## 주요 구성

### 시그널 전략
- 자본 규모별 분기 운영 (100만원 이하 집중 / 초과 분할)
- 모든 USDT 페어 실시간 스캔 → 후보 압축
- 최고 확률 종목 1개 자동 선택

### 리스크 관리
- **고정 손절**: -3% 도달 시 무조건 청산
- **트레일링 스탑**: 상승 시 익절선 자동 상향
- 매매 모드별 차별화 트레일링 (집중 1.5% / 분할 2%)

### ML 앙상블
- XGBoost · LightGBM · Random Forest 소프트 보팅
- 100+ 기술적 지표 자동 파생
- 실시간 예측 정확도 모니터링
- 자동 모델 재훈련 (12시간 주기)

### 실시간 대시보드
- 전략별 성과 추적 (집중 vs 분할)
- 거래·손익 분석
- ML 정확도 통계
- 일·주·월 리포트

### 텔레그램 알림
- 진입·청산 실시간 알림
- 포트폴리오 요약 (30분)
- 대시보드 리포트 (2시간)
- 오류 알림

## 빠른 시작

### 1. 환경 설정

```bash
git clone <repository>
cd binance_bot2
pip install -r requirements.txt
cp .env.example .env
# .env 편집하여 API 키 입력
```

### 2. .env 설정

```bash
# Binance API (필수)
BINANCE_API_KEY=your_api_key
BINANCE_SECRET_KEY=your_secret_key
USE_TESTNET=True  # 테스트넷: True, 실거래: False

# 거래 설정
TRADE_MODE=paper            # paper(가상) | live(실제)
MIN_USDT_24H_VOLUME=300000  # 최소 24h 거래량
ML_PROB_THRESHOLD=0.55      # ML 예측 임계값

# 텔레그램 알림 (선택)
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
```

### 3. 실행

```bash
# 시스템 테스트
python test_smart_bot.py

# 봇 실행
python main.py
```

## 매매 전략 상세

### 집중 운영 (자본 100만원 이하)
- **투입 비율**: 95% (5% 여유금)
- **스캔 주기**: 5분
- **트레일링**: 1.5% (공격적)
- **목표**: 고확률 신호 집중 투자

### 분할 운영 (자본 100만원 초과)
- **투입 비율**: 종목당 최대 20%
- **최대 보유**: 5개 동시
- **스캔 주기**: 15분
- **트레일링**: 2% (보수적)
- **목표**: 리스크 분산

### 신호 선택 로직

1. 모든 USDT 페어 스캔 (65개+ 종목)
2. ML 앙상블 확률 예측
3. 신뢰도 가중치 적용
4. 최고 점수 1개 선택
5. 기존 보유 확인
6. 매매 실행

## 주의사항

### 리스크 관리
- **테스트넷 우선**: 충분한 테스트 후 실거래로
- **소액 시작**: 감당 가능한 금액만
- **시장 변동성**: 암호화폐는 고변동성 자산

### 기술적 제한
- **API 제한**: 바이낸스 API rate limit 준수
- **네트워크**: 안정적 인터넷 필수
- **운영**: 24/7 실행 위해 VPS 권장

## 문제 해결

### 자주 발생하는 문제
1. **API 키 오류** — `.env` 파일 키 확인
2. **잔고 부족** — 최소 거래 금액($10) 확인
3. **네트워크 오류** — 인터넷 연결 확인
4. **모델 로드 실패** — 초기 실행 시 자동 훈련

### 로그 확인
```bash
tail -f logs/trading_bot.log         # 전체 로그
grep ERROR logs/trading_bot.log      # 오류만
```
